# Unidad 1: Fundamentos de Python y Geometría Computacional

En esta unidad se sientan las bases de programación científica y cálculo matricial para gráficos por computadora:

- Configuración del entorno de desarrollo.
- Álgebra vectorial en 2D y 3D.
- Uso de NumPy para operaciones vectorizadas y broadcasting.
- Visualización de datos y curvas con Matplotlib.

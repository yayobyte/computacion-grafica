# Unidad 3: Escenas Gráficas, Animación y Simulación

Esta unidad aborda la composición de escenas, interacción y animación:

- Renderizado de escenas y proyecciones (paralela y perspectiva).
- Modelos básicos de color, sombreado e iluminación.
- Animación cuadro a cuadro, interpolaciones y control temporal.
- Proyecto final integrador.
